# DeepSeekちゃん デスクトップAI

DeepSeek APIによる会話、音声合成、キャラクター表示を組み合わせた Windows 向け Electron アプリの開発用ソースです。会話を重ねながら、自然な表情や動きで寄り添うデスクトップAIを目指しています。

## 主な機能

- DeepSeek APIによる会話と履歴の保存、ストリーミング応答
- Live2Dの表情・動作、音声に合わせた口パク（対応モデルと実行部品が別途必要）
- Qwen3-TTSの音声合成、割り込み、思考フィラー（音声エンジン・モデル等が別途必要）
- 15感情、自然な待機動作、即時リアクション、音声簡潔モード
- 任意で有効化できる長期記憶、自発的なフォローアップ、ローカルカレンダー
- 集中モードや授業時間に配慮する通知制御

追加機能には初期状態でオフのものがあります。設定画面で必要な機能を選択してください。

## このリポジトリについて

これは開発用ソースで、**ダウンロードするだけですぐに動く完成版ではありません**。Live2Dモデル、そのテクスチャ・モーション、Cubism Coreおよび関連する表示ライブラリ、Qwen音声モデル、動画由来の参照音声、実行用Python環境、Electron配布物は含みません。利用する素材やソフトウェアは各自で入手し、利用・再配布条件を確認してください。キャラクター画像も含みません。

現状のコードには特定モデル向けのパラメータやファイルパスがあり、別のモデルを読み込むには調整が必要です。Qwenサーバーも特定のランタイム構成と参照音声を前提としており、手動での準備と設定が必要です。新しいPCでの導入手順は未検証です。

## 開発環境

- Windows 64ビットを主な対象としています。
- Node.js 18以上、npm。Electronの依存関係は `resources/app/package.json` を参照してください。
- 会話にはインターネット接続と各自のDeepSeek APIキーが必要です。API利用には費用が発生する場合があります。
- 音声とLive2D表示には、別途利用条件を満たすモデル・ランタイムの準備が必要です。

## セットアップと動作確認

PowerShellでリポジトリのフォルダーを開き、次を実行します。

```powershell
cd resources/app
npm install
npm test
npm run check
npm start
```

`npm start` は開発用の起動です。上記の不足素材があるため、キャラクター表示や音声は利用できない場合があります。`npm install` は依存パッケージをダウンロードします。`package-lock.json` はこのソースには含まれていないため、依存バージョンの完全な再現は保証できません。

APIキーはアプリの設定画面や実行環境で自分のものを設定してください。キーや `.env`、履歴をGitHubに登録しないでください。会話内容はDeepSeek APIに送信されます。クラウド音声を設定した場合は読み上げテキストも設定先に送られます。

## データとプライバシー

設定、会話履歴、長期記憶、カレンダーは通常Electronのユーザーデータ領域に保存されます。記憶やデスクトップ連動、自発通知の利用は設定で管理できます。これらのデータ、APIキー、個人の参照音声はこのリポジトリに含めません。

## フォルダー構成

- `resources/app/main.js`：Electronのメイン処理
- `resources/app/preload.js`：画面とメイン処理の接続
- `resources/app/src/core/`：会話、音声、記憶、カレンダーなど
- `resources/app/renderer/`：画面とキャラクター制御
- `resources/app/tests/`：自動テスト
- `scripts/`：音声サーバー等の補助スクリプト

コード、モデル、SDK、音声、依存ライブラリの権利・ライセンスはそれぞれ異なります。第三者素材の権利はこのリポジトリによって付与されません。アプリを配布する際は、利用するLive2D SDKやモデル、音声素材を含め、それぞれの条件を確認してください。
